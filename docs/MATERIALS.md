# Материалы: предварительная структура каталога

Рынок: Россия. Дата исследования: 17 октября 2026. Прототип содержит иллюстративные материалы, без утверждений об актуальном наличии и без расчёта готовой кухни.

## Разделение характеристик

Нужно хранить отдельно основу, покрытие, декор, фактуру, финиш и область применения. Например, дубовый рисунок может быть декором ЛДСП, плёнкой на МДФ или натуральным шпоном — одинаковое название цвета не делает материалы взаимозаменяемыми.

Для настоящего каталога: идентификатор, производитель, артикул, основа, покрытие, декор, толщина, финиш, применимость, ограничения формы фасада, ссылка на источник, дата проверки, регион наличия, единица цены, диапазон цены. Для 3D: разрешённые текстуры, физический масштаб рисунка, направление волокон, карты рельефа и шероховатости.

Не сравнивать цену панели за лист с ценой готового фасада за м² без нормализации. Для рыночного диапазона собрать сопоставимые предложения нескольких поставщиков: одинаковая основа, толщина, покрытие, обработка, регион и единица измерения. В карточке показывать источник и дату. В первую очередь нужны ориентиры по материалам, а не итоговая смета.

## Категории следующего этапа

- Корпуса: ЛДСП, толщина, кромка, видимые торцы.
- Фасады: ЛДСП; МДФ + ПВХ; МДФ + эмаль; HPL/PET/акриловые панели; шпон; массив.
- Геометрия фасада: гладкий, рамка, фрезеровка, витрина, интегрированная ручка — с проверкой совместимости покрытия.
- Столешницы: ДСП + декоративный пластик, компакт-HPL, акриловый камень, кварцевый агломерат.
- Фартук: панели, плитка, керамогранит, стекло.
- Ручки и профили: форма, цвет, размер и способ открывания.

Цвет на экране служит для подбора сочетания; фактическую отделку выбирают по физическому образцу.
