# План разработки

## Назначение

Человек вводит размеры своей кухни, выбирает кухонные модули, собирает их в помещении и сравнивает материалы. Основа рассчитана на последующее расширение на прихожие, гостиные и спальни.

## Этап 1 — прототип (этот репозиторий)

- [x] Комната, базовый оконный и дверной проём.
- [x] Каталог типовых модулей и размерные ряды.
- [x] Синхронные представления 2D, 3D и фасад.
- [x] Изменение расстановки, привязка, базовые геометрические проверки.
- [x] Иллюстративные материалы, сочетания, индивидуальный фасад.
- [x] Локальные варианты и перенос JSON.
- [x] Проверки основных геометрических правил.

## Этап 2 — реальное помещение

- [ ] Свободная форма стен, ниши, выступы, колонны, вентиляционные короба.
- [x] Четыре стены прямоугольной комнаты; толщина стен, точность 1 мм, размерные цепочки.
- [x] Проёмы на любой стене, настройка высоты, ширины, положения, подоконника и открывания.
- [x] Совместимость старых проектов через миграцию v1 → v2.
- [ ] Радиаторы, вода, канализация, электрические точки.
- [x] Пересечения с проёмами и сектор открывания входных дверей.
- [x] Размещение относительно стен и соседей с точными зазорами; отключаемые привязки.
- [x] Измерение перед фасадом и рекомендация ширины прохода между встречными рядами.
- [x] Типовое открывание мебельных фасадов и выдвижных ящиков в 2D/3D; проверка пути и пересечений открытых фасадов.
- [ ] Реальные петли, подъёмные механизмы, ручки в проверках и открывание оконных створок.
- [x] Скрытие ближних стен при перекрытии обзора.
- [ ] Свободная камера внутри комнаты.
- [ ] Шаблоны двухрядных и П-образных кухонь, остров и полуостров; расширенные проверки проходов.

## Этап 3 — каталог и визуализация

- [ ] 25–35 типов модулей: подъёмные фасады, разные схемы ящиков, угловые решения, вытяжки, мебельные доборы.
- [x] L-образный видимый угловой шкаф, непрерывные контуры столешниц и вырезы мойки/варочной панели.
- [x] Нижние, верхние и высокие доборы точной ширины 10–300 мм; подбор по промежуткам.
- [x] Корпуса, полки за стеклом и чаша мойки в 3D.
- [ ] Монтажные стыки столешниц, параметры видимых торцов и подробные угловые механизмы.
- [ ] Отдельные фасад/корпус/кромка/фартук; совместимость материала и формы.
- [ ] 30–50 проверенных декоров: производитель, код, размер текстуры, доступные покрытия.
- [ ] Реальные размеры ниш для техники по выбранной модели производителя.
- [ ] Более качественные модели техники, освещение, текстуры и рендер.
- [ ] Компактные карточки свойств и ориентировочной стоимости материалов.

## Этап 4 — сохранение и сравнение

- [ ] Сравнение двух вариантов рядом, единый ракурс.
- [ ] Пользовательские аккаунты и сохранение в облаке.
- [ ] Ссылка для просмотра без права редактирования.
- [ ] Экспорт нескольких изображений и плана в одном документе.
- [ ] Опциональная высококачественная визуализация, сохраняющая размеры и конфигурацию.

## Архитектурный принцип расширения

Общая сцена помещения, координаты, материалы и история изменений остаются едиными. Новые типы мебели добавляются через каталоги и генераторы геометрии. Кухонные правила отделяются от правил для шкафов, тумб и другой мебели.

Перед масштабированием стоит разнести React-компоненты по каталогам room/catalog/materials/projects, выделить историю в hook, добавить миграции формата проекта и отделить параметры техники от универсальных шкафов.

## Что проверяем с пользователем на прототипе

1. Понятно ли, как задать размеры своей комнаты?
2. Получается ли собрать прямую и угловую кухню без объяснений?
3. Достаточно ли точен и удобен перенос модулей на плане?
4. Помогают ли три вида проекта и смена отделок принять решение?
5. Какие реальные модули и материалы нужно добавить первыми?
